# CodeAlpha Internship – Data Analytics

This repository contains my Data Analytics internship projects completed during my internship at CodeAlpha.

## 📂 Projects

### 🔹 Task 1 – Data Visualization: IPL
- IPL dataset analysis and visualization
- Created charts to identify important patterns and trends
- Tools: Python, Pandas, Matplotlib, Seaborn

### 🔹 Task 2 – EDA: World Happiness
- Exploratory Data Analysis of the World Happiness dataset
- Performed data cleaning and statistical analysis
- Created visualizations and identified key insights
- Tools: Python, Pandas, Matplotlib, Seaborn

### 🔹 Task 3 – Sentiment Analysis: Amazon Reviews
- Performed sentiment analysis on Amazon customer reviews
- Analyzed review patterns and sentiment distribution
- Tools: Python, Pandas, NLP, Matplotlib, Seaborn

### 🔹 Task 4 – Web Scraping
- Collected and analyzed data using web scraping techniques
- Performed data processing and exploratory analysis
- Tools: Python, BeautifulSoup, Pandas
