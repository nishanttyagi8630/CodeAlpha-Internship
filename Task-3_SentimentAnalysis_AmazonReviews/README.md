# CodeAlpha_SentimentAnalysis_AmazonReviews 💬

## Task 4: Sentiment Analysis — CodeAlpha Data Analytics Internship

### 📌 Objective
Classify Amazon Fine Food Reviews as Positive, Negative, or Neutral using NLP techniques, and analyze how sentiment correlates with star ratings.

### 🛠 Tools & Libraries Used
- Python
- Pandas, NumPy
- TextBlob (NLP sentiment scoring)
- WordCloud
- Matplotlib, Seaborn

### 🌐 Data Source
Amazon Fine Food Reviews — Kaggle

### 🔍 Process
1. Cleaned dataset and sampled 5,000 reviews for efficient processing.
2. Used TextBlob to compute sentiment polarity for each review.
3. Classified reviews into Positive, Negative, and Neutral categories.
4. Visualized overall sentiment distribution and percentage breakdown.
5. Compared sentiment against star ratings to validate consistency.
6. Generated word clouds highlighting frequent terms in positive vs negative reviews.

### 📊 Key Insights
- Majority of reviews are Positive, consistent with high average star ratings.
- Sentiment strongly correlates with star ratings — 1-2 star reviews are mostly Negative, 4-5 star reviews mostly Positive.
- Positive reviews frequently mention words like "great," "love," and "delicious."
- Negative reviews highlight terms like "disappointed," "bad," and "waste."
- Sentiment Analysis offers a scalable way for businesses to track customer satisfaction from text feedback.

### 📁 Files
- `sample_sentiment_results.csv` — Processed sample with sentiment labels
- `sentiment_distribution.png` — Sentiment count distribution
- `sentiment_vs_rating.png` — Sentiment breakdown by star rating
- `sentiment_pie.png` — Overall sentiment percentage
- `wordcloud_positive.png` — Word cloud of positive reviews
- `wordcloud_negative.png` — Word cloud of negative reviews
