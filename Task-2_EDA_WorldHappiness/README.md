# CodeAlpha_EDA_WorldHappiness 🌍

## Task 2: Exploratory Data Analysis — CodeAlpha Data Analytics Internship

### 📌 Objective
Perform Exploratory Data Analysis on the World Happiness Report (2015) dataset to uncover trends, patterns, and relationships between happiness and its contributing factors.

### 🛠 Tools & Libraries Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn

### 🌐 Data Source
World Happiness Report 2015 — Kaggle

### 🔍 Process
1. Loaded and explored dataset structure (shape, data types, missing values).
2. Analyzed statistical summary of all numeric features.
3. Identified top 10 and bottom 10 happiest countries.
4. Computed average happiness score by region.
5. Built a correlation heatmap to study relationships between factors.
6. Visualized GDP and Family (Social Support) against Happiness Score.

### 📊 Key Insights
- Western Europe and North America report the highest average happiness scores; Sub-Saharan Africa the lowest.
- GDP per Capita, Family support, and Health strongly correlate with happiness.
- Switzerland, Iceland, and Denmark are the top 3 happiest countries in 2015.
- Trust in government shows a weaker correlation than economic/social factors.
- Happiness is multi-dimensional — strong social support can offset lower GDP.
